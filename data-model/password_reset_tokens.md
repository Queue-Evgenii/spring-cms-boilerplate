# password_reset_tokens

**Статус: запланировано.** Миграции ещё нет (будет отдельная, после основного потока входа).

Одноразовые токены сброса пароля.

| Колонка | Тип | Null | По умолчанию | Описание |
|---|---|---|---|---|
| `id` | uuid | нет | `uuidv7()` | Первичный ключ |
| `user_id` | uuid | нет | | FK на `users(id)` |
| `token_hash` | varchar(64) | нет | | Хеш токена (например SHA-256 в hex). Сам токен только в письме |
| `expires_at` | timestamptz | нет | | Короткий срок жизни (например 30 минут) |
| `used_at` | timestamptz | да | | Когда использован. Токен одноразовый |
| `created_at` | timestamptz | нет | `now()` | |

## Индексы и ограничения

- PK по `id`.
- FK `user_id` на `users(id)`.
- Уникальный индекс по `token_hash`.
- Индекс по `user_id` для отзыва старых токенов пользователя.

## Правила

- Токен генерируется криптостойко, хранится только хеш.
- При сбросе: все прежние неиспользованные токены пользователя аннулируются, `failed_login_attempts = 0`, `locked_until = NULL`, `must_change_password = false`, обновляется `password_changed_at`, сессии пользователя отзываются.
- После сброса пароля вход всё равно проходит через TOTP.
